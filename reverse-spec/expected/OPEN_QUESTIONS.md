# RoomFlow 미결정 질문

## OPEN-001. 최초 예약 조회 기간은 며칠인가?

- 선택지 A: 오늘부터 7일
  - 근거: `PPT:S3`, `PPT:S8`
- 선택지 B: 오늘부터 30일
  - 근거: `XLSX:화면목록!E5`, `XLSX:검토메모!A5:G5`
- 영향: 최초 조회 조건, 조회 건수, 성능 테스트 데이터
- 결정 필요자: 서비스 기획·업무 담당자

## OPEN-002. APPROVED 예약은 언제까지 취소할 수 있는가?

- 선택지 A: 시작 2시간 전까지
  - 근거: `PPT:S5`, `PPT:S8`
- 선택지 B: 시작 4시간 전까지
  - 근거: `XLSX:버튼이벤트!A8:J8`, `XLSX:검토메모!A6:G6`
- 영향: 취소 버튼 노출, `CANCEL_WINDOW_EXPIRED`, 취소 인수 테스트
- 결정 필요자: 회의실 운영 정책 담당자

## OPEN-003. 예약 목적은 필수인가?

- 선택지 A: 필수
  - 근거: `PPT:S4`, `PPT:S8`
- 선택지 B: 선택 항목
  - 근거: `XLSX:화면항목정의!A14:I14`, `XLSX:검토메모!A7:G7`
- 영향: 폼 표시, 입력 검증, 데이터 모델
- 결정 필요자: 서비스 기획·승인 업무 담당자

## OPEN-004. “빠르게”의 측정 가능한 응답 목표는 무엇인가?

- 현재 근거: 사용자가 기다리지 않게 빠르게 표시
  - 위치: `PPT:S3`, `PPT:S8`, `XLSX:검토메모!A8:G8`
- 빠진 정보: 측정 구간, 목표 시간, 백분위, 데이터 규모, 네트워크 조건
- 영향: NFR, 성능 테스트, 완료 판정
- 결정 필요자: 제품·개발·QA 담당자

수치가 합의되기 전에는 NFR을 만들지 않는다.

## OPEN-005. 예약 취소 알림을 어떤 채널로 보내는가?

- 후보: 이메일 또는 앱 알림
  - 근거: `PPT:S5`, `XLSX:검토메모!A9:G9`
- 다른 원본: Excel에는 확정 채널이 없음
- 영향: 알림 구현 범위, 실패 처리, 메시지 템플릿
- 결정 필요자: 서비스 기획·운영 담당자

## OPEN-006. 관리자가 승인자를 대신해 처리할 수 있는가?

- 후보: 관리자 대리 승인 허용
  - 근거: `PPT:S6`, `XLSX:버튼이벤트!A13:J13`, `XLSX:메시지·권한!A13:H13`
- 현재 상태: 검토중, 정책 승인 필요
- 영향: 권한 모델, 감사 기록, 승인함 노출 범위
- 결정 필요자: 보안·업무 정책 담당자

결정 전까지 관리자 대리 승인은 확정 기능으로 구현하지 않는다.
