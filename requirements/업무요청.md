# 업무 요청: IPS WBS 출고 기능 개선

재고 담당자가 WBS별 재고를 확인하고 출고할 수 있는 화면을 만들어 주세요.

- 출고하면 재고가 줄어야 합니다.
- 출고 완료 건은 취소할 수 있어야 합니다.
- 취소하면 재고를 다시 돌려놓아야 합니다.
- WBS에 따라 SAP 이동유형이 다릅니다.
- 같은 출고가 두 번 처리되면 안 됩니다.

## 참고 정보

- 일반 프로젝트 출고/취소 이동유형: `221` / `222`
- 가수주 출고/취소 이동유형: `M75` / `M76`
- 하자보수 출고/취소 이동유형: `M77` / `M78`
- 실제 시스템은 IPS에서 SAP 함수를 호출하지만, 교육용 MVP는 외부 시스템 없이 로컬에서 동작하면 됩니다.

## 현재 제공된 것

- 한 화면으로 구성된 사용자 인터페이스
- API 경로와 요청 모델
- 데모 재고 3건
- 메모리 기반 재고·출고 저장소
- 아직 통과하지 않는 자동 테스트

그 밖의 기능 범위, 데이터 계약, 상태, 오류 처리, 원자성, 중복 판정, Architecture와 AI 작업 범위는 아직 승인되지 않았습니다.
