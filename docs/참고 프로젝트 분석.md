# 구매시스템(IPS) 입출고 기능개선 분석과 교육 MVP 축소

## 1. 분석한 제공 자료

| 자료 | 확인한 핵심 내용 |
|---|---|
| 요구사항정의서 V1.1 | SAP 재고 동기화와 IPS 출고·승인·취소·메일 등 27개 요구사항 |
| WBS 출고 기술설계서 | 출고 입력, 재고 차감, WBS별 이동유형, 처리 후 재고 반환 |
| WBS 출고 취소 기술설계서 | 원본 자재문서 전체 취소, 취소 후 재고 반환 |
| 재고 동기화 기술설계서 | 수동·자동 동기화, 플랜트·저장위치·프로젝트 재고와 단가 계산 |

요구사항정의서에는 수용 25건, 기각 1건, 검토 1건이 있습니다. 실제 범위는 재고 처리 외에도 SAP 인터페이스, 전자결재, 화면 조건, 메일, 담당자 자동 지정까지 포함합니다.

## 2. 전체 시스템을 2시간 실습에 사용할 수 없는 이유

- SAP BAPI와 IPS 간 인터페이스 환경이 필요합니다.
- 전자결재 승인·반려 상태와 메일 발송까지 연결됩니다.
- 자동 배치와 수동 재고 동기화의 실행 방식이 다릅니다.
- 일반·프로젝트 재고, 플랜트, 저장위치, 단가·금액 계산을 모두 다뤄야 합니다.
- 외부 연동을 모사하더라도 요구사항 25건의 스펙과 검증은 2시간을 넘습니다.

## 3. 교육에 가져올 업무 규칙

- 재고는 자재·플랜트·저장위치·WBS 조합으로 식별합니다.
- 출고 수량만큼 가용 재고를 차감합니다.
- WBS 종류에 따라 이동유형이 달라집니다.
- 완료된 출고는 항목별이 아니라 전체 취소합니다.
- 취소하면 출고 수량 전체를 동일 재고에 원복합니다.
- 성공 결과뿐 아니라 실패 시 데이터가 바뀌지 않아야 합니다.

## 4. 120분 MVP의 경계

```text
실제 IPS/SAP 전체
  └─ 재고·입고·출고·결재·메일·배치·권한
       └─ 교육 MVP
            재고 조회 → 즉시 출고 → 전체 취소
```

### 포함

1. 데모 WBS 재고 조회
2. 출고 입력 검증과 즉시 처리
3. 재고 차감과 출고 이력
4. WBS별 출고·취소 이동유형
5. 완료 출고 전체 취소와 재고 원복
6. 재고 부족, 중복 요청, 중복 취소 검증

### 제외

1. SAP BAPI와 실제 인터페이스
2. 전자결재와 승인·반려
3. 입고, 품질검사 입고, 재고 마이그레이션
4. 자동·수동 재고 동기화 실행
5. 메일, 사용자·창고 담당자 자동 지정
6. 인증·권한·DB·동시성·운영 배포

## 5. 2시간 적합성

| 기준 | 판단 |
|---|---|
| 시작과 종료가 명확한가 | 재고 선택에서 취소 원복까지 닫힌 흐름 |
| 업무 규칙이 있는가 | 재고, 중복, 상태, 이동유형 결정표 |
| 결과가 눈에 보이는가 | 재고 수량과 출고 상태 변화 |
| 오류를 만들 수 있는가 | 재고 부족, 중복 요청·취소 |
| 외부 연동 없이 가능한가 | SAP 역할을 로컬 메모리로 모사 |
| 자동 검증 가능한가 | 차감·원복 수량과 상태를 결정적으로 비교 |

## 6. 실제 시스템으로 확장하는 순서

교육 MVP가 끝난 뒤에는 한 번에 전체를 붙이지 않고 다음 순서로 확장합니다.

1. 출고 요청과 승인 상태 분리
2. DB 저장과 트랜잭션·동시성 제어
3. 수동 재고 동기화
4. SAP 어댑터와 실패 재처리
5. 전자결재와 메일
6. 자동 배치와 운영 모니터링
