# IPS WBS 출고·취소 MVP 기능명세

- 버전: 1.0
- 실습 시간: 120분
- 대상 사용자: 재고 담당자
- 참고 자료: IPS 입출고 요구사항정의서, WBS 출고·출고 취소·재고 동기화 기술설계서

## 1. 한 줄 정의

> 재고 담당자가 WBS 재고를 선택해 출고하면 가용 재고가 차감되고, 완료된 출고를 전체 취소하면 같은 수량이 원복되는 로컬 업무 시스템입니다.

## 2. 해결할 문제

원본 자료의 구매시스템은 SAP 재고, 전자결재, 메일, 배치 작업까지 연결됩니다. 이를 그대로 구현하면 2시간 동안 환경 구성과 외부 연동에 시간이 소모됩니다. 교육에서는 업무적으로 완결된 최소 흐름만 남겨 다음을 연습합니다.

- 모호한 업무 요청을 검증 가능한 규칙으로 바꾸기
- 재고와 출고 상태가 함께 변하는 조건 정의하기
- 정상 결과뿐 아니라 실패 시 불변 조건 정의하기
- 스펙 ID와 테스트를 연결해 AI 생성 결과 검증하기

## 3. 사용자 흐름

```mermaid
flowchart LR
    A[WBS 재고 조회] --> B[재고 행 선택]
    B --> C[출고 요청]
    C --> D{입력·재고 검증}
    D -->|성공| E[재고 차감·출고 완료]
    D -->|실패| F[변경 없이 오류]
    E --> G[전체 취소]
    G --> H[재고 원복·취소 완료]
```

## 4. 포함 범위

1. 데모 재고 전체 조회와 WBS 정확 일치 조회
2. 출고 요청 번호, 자재, 플랜트, 저장위치, WBS, 수량, 처리자 입력
3. WBS 접두사에 따른 출고·취소 이동유형 결정
4. 재고가 충분한 경우 전체 수량 출고와 즉시 차감
5. 출고 완료 이력 조회
6. 출고 완료 건의 전체 취소와 재고 원복
7. 필수값, 수량, 재고 부족, 중복 요청, 중복 취소 오류
8. 데모를 반복하기 위한 초기화 기능

## 5. 제외 범위

- 실제 SAP 및 BAPI 호출
- 입고와 품질검사 입고
- 자동·배치 재고 동기화와 마이그레이션
- 전자결재 상신·승인·반려
- 메일과 알림
- 부분 출고와 부분 취소
- 인증, 권한, 조직 정보
- 데이터베이스 영구 저장과 동시성 제어
- 금액, 단가, 회계 전표 처리
- 운영 배포와 장애 복구

## 6. 상태

| 상태 | 의미 | 가능한 다음 행동 |
|---|---|---|
| `COMPLETED` | 출고와 재고 차감 완료 | 전체 취소 |
| `CANCELED` | 취소와 재고 원복 완료 | 없음 |

별도의 요청·승인 상태는 만들지 않습니다. 이번 MVP에서 출고 요청은 검증 성공 시 즉시 완료됩니다.

## 7. 완료 모습

- 한 화면에서 현재 재고와 출고 이력을 함께 봅니다.
- 재고 행을 선택하고 수량을 입력해 출고합니다.
- 출고 직후 재고 감소와 이동유형을 확인합니다.
- 출고 완료 건을 취소하고 원래 수량으로 복구되는 것을 확인합니다.
- 잘못된 요청은 데이터 변경 없이 한국어 오류를 표시합니다.
