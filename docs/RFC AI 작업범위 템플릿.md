## 6. 작업 순서

1. 관련 SPEC, ADR, 테스트를 읽는다.
2. 구현할 ID와 수정할 파일을 요약한다.
3. 범위 충돌 여부를 확인한다.
4. 허용된 파일만 수정한다.
5. 관련 테스트 후 전체 회귀 테스트를 실행한다.
6. 변경 파일, 통과한 ID, 남은 위험을 보고한다.

## 7. 중단·질문 조건

AI는 다음 상황에서 추정하거나 우회하지 않고 작업을 중단한 뒤 질문합니다.

- SPEC과 테스트가 충돌하는 경우
- 허용 목록 밖 파일 수정이 필요한 경우
- 새 의존성 또는 외부 네트워크가 필요한 경우
- 데이터 삭제·마이그레이션이 필요한 경우
- 보안·개인정보 위험을 발견한 경우
- 완료 조건을 만족시키는 방법이 두 가지 이상이고 업무 결과가 달라지는 경우

보고 형식:

```text
중단 이유:
관련 SPEC/ADR/RFC ID:
필요한 추가 결정:
선택지와 영향:
권장 최소 변경:
```
