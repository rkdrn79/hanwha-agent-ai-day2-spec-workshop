# 업무 배경: IPS WBS 출고 흐름 개선

재고 담당자는 프로젝트별 WBS에 배정된 자재를 확인하고 출고합니다. 현재 재고 확인, 출고 처리, 취소 결과 확인이 분리되어 있어 업무 흐름을 한번에 파악하기 어렵습니다.

특히 다음 상황을 줄이고 싶습니다.

- 같은 출고 요청이 두 번 처리되어 재고가 중복 차감되는 문제
- 재고가 부족한데도 일부 데이터가 변경되는 문제
- 취소 후 실제 재고와 출고 이력이 맞지 않는 문제
- WBS 유형에 맞지 않는 출고·취소 이동유형을 사용하는 문제
- 처리 실패 이유를 화면에서 알 수 없는 문제

교육용 MVP는 실제 SAP를 연결하지 않고 로컬 메모리 데이터로 이 흐름을 재현합니다.

## 주요 사용자

- **재고 담당자**: 재고를 선택하고 출고·취소를 수행합니다.
- **업무 관리자**: 출고·취소 결과와 업무 규칙 준수 여부를 확인합니다.

## 제외 범위

- 실제 SAP 연동
- 로그인·권한·전자결재
- 부분 취소와 다건 일괄 처리
- 운영 DB·배포·모니터링
- 단가·금액·메일링
