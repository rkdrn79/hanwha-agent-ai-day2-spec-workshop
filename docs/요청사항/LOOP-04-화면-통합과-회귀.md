# LOOP-04: Frontend·Backend 통합과 회귀

## 인도 목표

- Frontend와 Backend가 승인된 API 계약으로 동작합니다.
- 재고·출고 이력을 새로고침하고 로딩·오류·빈 상태를 보여줍니다.
- 완료 건만 취소 가능하고, 취소 건은 상태와 취소 이동유형을 보여줍니다.
- 데모 초기화 후 재고·이력·폼이 시작 상태로 돌아옵니다.
- 전체 자동 테스트와 브라우저 스모크를 통과합니다.
- RFC에서 금지한 파일의 변경이 없는지 확인합니다.

## 브라우저 검증 장면

1. `IM24-001` 재고를 선택합니다.
2. `12`를 출고해 `88`과 `COMPLETED`를 확인합니다.
3. 같은 요청을 재전송해 오류와 재고 `88`을 확인합니다.
4. 완료 건을 취소해 `100`과 `CANCELED`를 확인합니다.
5. 재취소 시도는 API 검증으로 재고 불변을 확인합니다.

## 검증 통과 직후 CHANGELOG

통합 화면과 전체 회귀가 통과하면 재현한 흐름, 테스트 결과, 남은 제약을 즉시 기록하고 LOOP-04 단위로 commit합니다. 실습 마지막에는 네 LOOP의 누락과 버전 표기만 정리합니다.
