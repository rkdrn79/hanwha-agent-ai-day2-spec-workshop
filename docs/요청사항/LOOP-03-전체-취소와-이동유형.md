# LOOP-03: 전체 취소와 WBS 이동유형

## 인도 목표

- `COMPLETED` 출고만 전체 취소합니다.
- 원 출고 수량 전체를 원복하고 상태를 `CANCELED`로 바꿉니다.
- 취소자·취소 시각·취소 이동유형을 남깁니다.
- 재취소는 실패하고 재고는 변하지 않습니다.
- WBS 유형에 맞는 출고·취소 이동유형 쌍을 사용합니다.

## 검증 장면

- 일반 WBS: `221 / 222`
- 가수주 WBS: `M75 / M76`
- 하자보수 WBS: `M77 / M78`
- `100 → 88 → 100`

## 검증 통과 직후 CHANGELOG

위 장면이 통과하면 전체 취소, 재취소 방어, 이동유형 규칙을 즉시 기록하고 LOOP-03 단위로 commit합니다. 실패 상태에서는 기록하지 않습니다.
