# 요청사항 읽는 순서

이 폴더는 현업이 전달한 요청과 인도 단위의 작업 요청을 담습니다. 어떤 파일도 SPEC이나 설계 정답이 아닙니다.

1. `00-업무-배경.md`와 `01-MVP-요구사항.md`를 읽고 질문을 만듭니다.
2. 합의한 답으로 SPEC·Architecture·ADR·RFC를 승인합니다.
3. `LOOP-01`부터 `LOOP-04`까지 하나씩 구현·검증합니다.
4. 각 루프가 실제로 통과한 후에만 CHANGELOG를 추가합니다.

후속 LOOP는 SPEC을 매번 다시 쓰는 문서가 아닙니다. 최초 SPEC의 인수 조건을 작은 인도 단위로 나눈 작업 요청입니다.
