# LOOP-02: 안전한 출고

## 인도 목표

- 필수 문자열의 공백을 정리하고 빈 값을 거부합니다.
- 수량 `0`·음수를 거부합니다.
- 재고가 부족하면 현재 재고와 요청 수량을 알려줍니다.
- 이미 처리된 요청을 다시 보내면 거부합니다.
- 모든 실패는 재고와 이력을 변경하지 않습니다.
- Frontend는 오류 이유를 보여주고 요청 중 중복 클릭을 막습니다.

## 검증 장면

- `101` 출고는 실패하고 재고는 `100`, 이력은 0건입니다.
- 성공한 `request_id`를 다시 사용하면 실패하고 재고는 한 번만 차감됩니다.
