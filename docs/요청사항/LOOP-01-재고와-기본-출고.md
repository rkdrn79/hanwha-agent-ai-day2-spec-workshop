# LOOP-01: 재고 선택과 기본 출고

## 인도 목표

- Frontend에 데모 재고 3건을 표시합니다.
- WBS 필터로 정확히 일치하는 재고를 찾습니다.
- 재고 행을 선택하면 출고 폼에 식별값을 채웁니다.
- 유효한 출고 요청이 현재 재고를 차감하고 `COMPLETED` 이력을 남깁니다.

## 검증 장면

`IM24-001` 재고 `100`에서 `12`를 출고하면 재고는 `88`이고 이력은 1건입니다.

## 검증 통과 직후 CHANGELOG

위 장면이 통과하면 재고 조회·선택·기본 출고 행동을 즉시 기록하고 LOOP-01 단위로 commit합니다. 실패 상태에서는 기록하지 않습니다.
