# IPS WBS 출고·취소 MVP 구현스펙

- 버전: 1.0
- 상태: 승인
- 기준 기능명세: `docs/IPS MVP 기능명세.md`

## 1. 목표

재고 조회부터 출고, 전체 취소까지 하나의 닫힌 업무 흐름을 구현합니다. 성공하면 재고와 이력이 함께 바뀌고, 실패하면 둘 다 바뀌지 않아야 합니다.

## 2. 데이터 계약

### 재고

| 필드 | 형식 | 필수 | 의미 |
|---|---|---:|---|
| `material_code` | 문자열 | 예 | 자재코드 |
| `material_name` | 문자열 | 예 | 화면 표시명 |
| `plant` | 문자열 | 예 | 플랜트 |
| `storage_location` | 문자열 | 예 | 저장위치 |
| `wbs` | 문자열 | 예 | 프로젝트 WBS |
| `quantity` | 정수 | 예 | 가용 재고, 0 이상 |
| `unit` | 문자열 | 예 | 수량 단위 |

재고 식별 키는 `material_code + plant + storage_location + wbs`입니다.

### 출고 요청

| 필드 | 형식 | 필수 | 제한 | 예시 |
|---|---|---:|---|---|
| `request_id` | 문자열 | 예 | 공백 제외, 전체 이력에서 고유 | `GI-001` |
| `material_code` | 문자열 | 예 | 재고 키와 일치 | `A39439-00001213` |
| `plant` | 문자열 | 예 | 재고 키와 일치 | `7311` |
| `storage_location` | 문자열 | 예 | 재고 키와 일치 | `1M01` |
| `wbs` | 문자열 | 예 | 재고 키와 일치 | `IM24-001` |
| `quantity` | 정수 | 예 | 1 이상, 가용 재고 이하 | `10` |
| `user_id` | 문자열 | 예 | 공백 제외 | `H0001` |

### 출고 결과

| 필드 | 의미 |
|---|---|
| `shipment_id` | 실행 중 증가하는 출고 식별자 |
| `movement_type` | 출고 이동유형 |
| `cancel_movement_type` | 취소 후 기록되는 취소 이동유형 |
| `status` | `COMPLETED` 또는 `CANCELED` |
| `stock_after` | 현재 처리 직후 가용 재고 |
| `completed_at` | 출고 완료 시각 |
| `canceled_at`, `canceled_by` | 취소 완료 시각과 처리자 |

## 3. API

| 메서드·경로 | 역할 | 정상 응답 |
|---|---|---|
| `GET /api/inventory` | 전체 재고 조회 | `{inventory: [...]}` |
| `GET /api/inventory?wbs=...` | WBS 정확 일치 조회 | `{inventory: [...]}` |
| `POST /api/shipments` | 출고 처리 | 생성된 출고 객체 |
| `GET /api/shipments` | 최신 순 출고 이력 | `{shipments: [...]}` |
| `GET /api/shipments/{id}` | 출고 상세 | 출고 객체 |
| `POST /api/shipments/{id}/cancel` | 출고 전체 취소 | 변경된 출고 객체 |
| `POST /api/demo/reset` | 교육용 초기화 | `{status: "reset"}` |

업무 오류는 HTTP 400과 `{detail: "메시지"}`로 반환합니다.

## 4. 처리 규칙

| ID | 규칙 |
|---|---|
| FR-01 | 모든 문자열 입력은 앞뒤 공백을 제거한 뒤 필수 여부를 검사합니다. |
| FR-02 | 출고 수량은 1 이상의 정수여야 하며 자동 보정하지 않습니다. |
| FR-03 | 입력한 복합 키와 정확히 일치하는 재고가 있어야 합니다. |
| FR-04 | 요청 수량이 가용 재고보다 크면 일부 출고하지 않고 전체 실패합니다. |
| FR-05 | `request_id`가 기존 이력에 있으면 재고와 이력을 변경하지 않습니다. |
| FR-06 | 정상 출고는 재고에서 요청 수량 전체를 한 번 차감하고 `COMPLETED` 이력을 생성합니다. |
| FR-07 | 취소는 `COMPLETED` 출고의 원래 수량 전체만 허용합니다. 부분 취소 입력은 제공하지 않습니다. |
| FR-08 | 정상 취소는 원래 수량 전체를 같은 재고 키에 더하고 상태를 `CANCELED`로 변경합니다. |
| FR-09 | `CANCELED` 출고의 재취소는 재고와 이력을 변경하지 않습니다. |
| FR-10 | 목록은 현재 프로세스의 메모리에만 저장하며 출고 이력은 최신 순으로 표시합니다. |

## 5. 이동유형 결정표

대소문자와 무관하게 WBS 접두사를 확인합니다.

| 조건 | 출고 이동유형 | 취소 이동유형 |
|---|---:|---:|
| `R2-00`으로 시작 | `M75` | `M76` |
| `R2-01`로 시작 | `M77` | `M78` |
| 그 외 WBS | `221` | `222` |

## 6. 오류 계약

| ID | 상황 | 메시지 | 실패 후 불변 조건 |
|---|---|---|---|
| ER-01 | 필수 문자열 누락 | `<필드명>: 필수 입력값입니다.` | 재고·이력 불변 |
| ER-02 | 수량 1 미만 | `출고 수량은 1 이상이어야 합니다.` | 재고·이력 불변 |
| ER-03 | 재고 키 불일치 | `일치하는 재고를 찾을 수 없습니다.` | 재고·이력 불변 |
| ER-04 | 재고 부족 | `재고가 부족합니다. 현재 재고: N, 요청 수량: N` | 부분 차감·이력 생성 없음 |
| ER-05 | 출고 요청 번호 중복 | `이미 처리된 출고 요청 번호입니다.` | 추가 차감·이력 생성 없음 |
| ER-06 | 출고 ID 없음 | `출고 내역을 찾을 수 없습니다.` | 재고·이력 불변 |
| ER-07 | 이미 취소됨 | `이미 취소된 출고입니다.` | 추가 원복 없음 |
| ER-08 | 완료 상태가 아님 | `출고 완료 건만 취소할 수 있습니다.` | 재고·이력 불변 |

## 7. 인수 조건

### AC-01 입력 정리

```text
Given 필수 문자열 앞뒤에 공백이 있고 수량이 3일 때
When 출고 입력을 검증하면
Then 공백이 제거된 값과 수량 3을 반환한다.
```

### AC-02~03 입력 오류

```text
Given 요청 번호가 공백이거나 수량이 0일 때
When 출고를 요청하면
Then 지정된 오류를 반환하고 재고와 이력을 변경하지 않는다.
```

### AC-04 이동유형

```text
Given WBS가 IM24-001, R2-00-100, R2-01-200일 때
When 출고·취소 이동유형을 결정하면
Then 각각 221/222, M75/M76, M77/M78을 반환한다.
```

### AC-05~06 재고와 취소 상태 검증

```text
Given 가용 재고보다 많은 수량 또는 이미 취소된 출고일 때
When 출고 또는 취소를 요청하면
Then 오류를 반환하고 수량을 변경하지 않는다.
```

### AC-07 조회

```text
Given 데모 재고가 3건일 때
When 전체 또는 IM24-001 WBS로 조회하면
Then 각각 3건 또는 정확히 일치하는 1건을 반환한다.
```

### AC-08 정상 출고

```text
Given IM24-001 재고가 100이고 요청 수량이 12일 때
When 출고를 처리하면
Then 상태는 COMPLETED이고 이동유형은 221이며 재고는 88이다.
```

### AC-09 재고 부족 원자성

```text
Given 재고가 100이고 요청 수량이 101일 때
When 출고를 처리하면
Then 오류를 반환하고 재고는 100이며 출고 이력은 생성되지 않는다.
```

### AC-10 중복 요청

```text
Given GI-001 출고가 이미 완료되었을 때
When 같은 요청 번호로 다시 출고하면
Then 오류를 반환하고 추가 재고 차감과 이력 생성이 없다.
```

### AC-11 정상 전체 취소

```text
Given 재고 100에서 12를 출고한 완료 건이 있을 때
When 해당 출고를 취소하면
Then 상태는 CANCELED, 취소 이동유형은 222, 재고는 100이다.
```

### AC-12 중복 취소

```text
Given 출고가 이미 취소되어 재고가 100으로 원복되었을 때
When 다시 취소하면
Then 오류를 반환하고 재고는 100을 유지한다.
```

### AC-13 특수 WBS 전체 흐름

```text
Given R2-00-100 WBS 재고를 출고하고 취소할 때
Then 출고 이동유형은 M75이고 취소 이동유형은 M76이다.
```

## 9. 비기능 요구사항

| ID | 요구사항 | 확인 방법 |
|---|---|---|
| NFR-01 | 모든 핵심 업무 규칙은 화면과 분리해 자동 테스트할 수 있어야 합니다. | 엔진·서비스 테스트 |
| NFR-02 | 사용자 입력은 HTML 문자열로 직접 삽입하지 않습니다. | 화면 코드 검토 |
| NFR-03 | 데모 데이터는 파일·DB가 아닌 메모리에만 유지합니다. | 저장소 코드 검토 |
| NFR-04 | 오류 메시지는 화면에서 사용자가 다음 행동을 판단할 수 있어야 합니다. | 수동 검증 |
