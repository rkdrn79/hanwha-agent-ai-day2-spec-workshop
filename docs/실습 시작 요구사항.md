# 실습 시작 요구사항: IPS WBS 출고 기능 개선

> 이 문서는 의도적으로 구현에 부족한 상태입니다. 바로 코드를 생성하지 말고, 먼저 결정이 필요한 질문을 찾으십시오.

## 업무 요청

재고 담당자가 WBS별 재고를 확인하고 출고할 수 있는 화면을 만들어 주세요.

- 출고하면 재고가 줄어야 합니다.
- 출고 완료 건은 취소할 수 있어야 합니다.
- 취소하면 재고를 다시 돌려놓아야 합니다.
- WBS에 따라 SAP 이동유형이 다릅니다.
- 같은 출고가 두 번 처리되면 안 됩니다.

## 참고 정보

- 일반 프로젝트 출고/취소: `221` / `222`
- 가수주 출고/취소: `M75` / `M76`
- 하자보수 출고/취소: `M77` / `M78`
- 실제 시스템은 IPS에서 SAP 함수를 호출하지만 교육에서는 로컬에서 동작하면 됩니다.
