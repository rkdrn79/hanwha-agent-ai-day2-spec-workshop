# 사내추첨 MVP 기능명세

- 버전: 1.0
- 상태: 교육 기준선
- 대상: 한화 Agent AI 실무교육 2일차

## 1. 배경

사내 행사 진행자가 참여자 목록에서 당첨자를 뽑을 때 수기 추첨은 중복, 인원수 착오, 결과 설명의 어려움이 생길 수 있습니다. 실제 사내추첨시스템은 다양한 운영 기능과 연동을 포함하지만, 교육에서는 핵심 추첨 흐름만 작은 웹 MVP로 구현합니다.

## 2. 목표

행사 진행자가 별도의 운영 시스템 없이 참여자 목록과 당첨자 수를 입력하고, 유효한 참여자 중에서 중복 없는 당첨자를 뽑아 결과를 확인할 수 있어야 합니다.

## 3. 사용자

| 사용자 | 사용 상황 | 필요한 결과 |
|---|---|---|
| 행사 진행자 | 현장 또는 사전 추첨 | 당첨자와 입력 처리 요약 |
| 교육 수강생 | AI 생성 결과 검증 | 스펙과 테스트의 연결, 실패 원인 |

## 4. 핵심 사용자 흐름

1. 진행자가 참여자 이름을 한 줄에 한 명씩 입력합니다.
2. 진행자가 당첨자 수를 입력합니다.
3. 진행자가 `추첨하기`를 선택합니다.
4. 시스템이 공백, 빈 줄, 중복 이름을 정리합니다.
5. 시스템이 참여자와 당첨자 수를 검증합니다.
6. 조건이 올바르면 당첨자를 중복 없이 뽑습니다.
7. 시스템이 당첨자와 고유 참여자 수, 중복 제거 수를 보여 줍니다.
8. 진행자는 최근 실행 이력에서 추첨 시각과 결과를 확인합니다.

## 5. 주요 기능

| ID | 기능 | 설명 |
|---|---|---|
| F-01 | 참여자 입력 | 한 줄에 한 명씩 이름 입력 |
| F-02 | 입력 정리 | 공백·빈 줄·동일 이름 중복 제거 |
| F-03 | 당첨자 수 검증 | 1 이상, 고유 참여자 수 이하 확인 |
| F-04 | 무작위 추첨 | 중복 없는 당첨자 선택 |
| F-05 | 결과 표시 | 당첨자와 처리 요약 표시 |
| F-06 | 실행 이력 | 현재 실행 중 최근 추첨 기록 확인 |

## 6. 포함 범위

- 참여자 텍스트 직접 입력
- 단일 추첨 실행
- 테스트 시드를 사용한 재현 가능한 자동 검증
- 로컬 브라우저 화면과 API
- 메모리 기반 실행 이력

## 7. 제외 범위

- 로그인, 사번·조직 인증
- 온라인 응모와 취소
- 이벤트 등록·게시·기간 설정
- 파일 업로드
- 사용자·관리자 화면 분리
- 데이터베이스 영구 저장
- 블록체인·토큰 연계
- 재추첨, 당첨 포기, 알림
- 운영 서버 배포

## 8. MVP 완료 모습

- 정상 입력에서 요청한 수만큼 중복 없는 당첨자를 표시합니다.
- 중복 입력의 처리 결과를 숫자로 확인할 수 있습니다.
- 빈 입력과 잘못된 당첨자 수는 정확한 오류로 거부합니다.
- 자동 테스트에서 동일한 시드로 결과를 재현할 수 있습니다.
- 인수 조건과 자동·수동 검증 결과가 연결됩니다.

상세 입출력과 완료 기준은 `docs/사내추첨 MVP 구현스펙.md`에서 정의합니다.
