# Project → PowerPoint Brief template

새 프로젝트에서는 아래 항목을 복사해 `presentation/BRIEF.md` 또는 작업 폴더의 `BRIEF.md`에 채운다. 값이 없는 항목은 Skill이 근거를 조사해 가정으로 기록한다.

```markdown
# [프로젝트명] Project → PowerPoint Brief

## 목적과 청중
- 프로젝트 루트:
- 발표 목적:
- 청중:
- 발표 시간:
- 언어:

## 결과 조건
- 슬라이드 수 또는 허용 범위:
- 화면비:
- 작업 폴더:
- 결과 폴더:
- 결과 파일명:

## 근거
- 우선 확인할 위치:
- 제외할 위치와 이유:
- 문서 충돌 시 승인 기준:

## 이야기 방향
- 핵심 질문:
- 권장 흐름:
- 반드시 포함할 사실:

## 시각 스타일
- 템플릿 또는 스타일 레퍼런스:
- 브랜드 사용 권한:
- 색·타이포·여백 제약:

## 완료 조건
- 편집 가능한 PPTX
- 전 장 렌더와 contact sheet
- 사실·구조·시각·접근성 QA 보고서
```

장수·색·파일명은 예제 값을 복사하지 말고 발표 목적과 실제 프로젝트 조건으로 결정한다.
