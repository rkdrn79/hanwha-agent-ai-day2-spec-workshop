# Presentation design contract

이 문서는 특정 브랜드 스타일이 아니라, Brief와 실제 레퍼런스를 작업 가능한 시각 기준으로 번역하기 위한 체크리스트다. 발표 조건은 [brief-template.md](brief-template.md)를 사용한다.

## `design_contract.md`에 기록할 값

### 색과 의미

- 배경·본문·강조·증거·경고 색의 역할
- 텍스트 대비와 색각 이상에서도 구분되는 보조 표현
- 로고·브랜드 색 사용 권한

### 타이포그래피

- 한글·영문 대체 폰트 순서
- 제목·본문·캡션의 최소 크기
- 제목 줄 수와 본문 밀도 제한

### 레이아웃 문법

- 표지·섹션·본문·증거·비교·코드 화면의 레이아웃 패턴
- 같은 레이아웃의 연속 반복 제한
- 한 장의 주요 시각 객체 수와 여백 기준

### 근거 표현

- 파일·테스트·데이터·상태 흐름을 보여주는 방법
- 표의 최대 행 수와 코드·터미널의 최대 줄 수
- 발표자 노트에서 근거 위치를 기록하는 형식

### 검수 기준

- 템플릿 또는 레퍼런스와의 비교 방법
- 렌더링 결과에서 찾을 겹침·잘림·줄바꿈 문제
- QA 보고서에 남길 항목

스타일 레퍼런스가 없으면 청중과 목적에 맞는 단순하고 일관된 시스템을 새로 정의한다. 장식 요소가 실제 근거보다 먼저 보이지 않게 한다.
