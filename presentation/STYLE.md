# PPT 시각 계약

목표는 “AI가 카드를 자동 배치한 화면”이 아니라, 강사가 한 장씩 편집한 교육용 발표자료입니다.

## 기본 리듬

- 표지: 주황색 면 + 밝은 기하학 면, 큰 제목과 한 줄 설명
- 섹션: 전체 주황색 배경 + 한 줄의 큰 섹션명
- 본문: 흰색 배경 + 상단 주황색 제목 바 + 하단 근거 푸터
- 코드·프롬프트: 짙은 남회색 패널 하나만 사용
- 표: 남색 헤더, 업무 판정에 필요한 열만 남김

## 슬라이드별 우선 시각

1. 숫자 장: `100 → 88 → 100`을 화면의 주인공으로 만듭니다.
2. 문제 장: 파일 트리와 듣는 사람의 질문 순서를 비교합니다.
3. 흐름 장: 조회 → 출고 → 전체 취소를 한 줄 타임라인으로 보여줍니다.
4. 규칙 장: 중복·재고 부족·취소·재취소를 간단한 테스트 표로 보여줍니다.
5. 구조 장: Frontend → API → Service → Engine·Store 단일 흐름을 보여줍니다.
6. 검증 장: `23/23`을 크게, 어떤 테스트인지를 작게 보여줍니다.

## 제약

- 본문 핵심 글씨는 24pt 이상을 권장합니다.
- 한 장에 카드를 3개 이상 반복 배치하지 않습니다.
- 모든 장에 요약 필·배지·영어 라벨을 반복하지 않습니다.
- 장식용 아이콘 대신 실제 파일명·테스트·상태·숫자를 사용합니다.
- 오렌지는 강조와 전환에만, 남색은 근거·표·구조에 사용합니다.

## 색상 기준

- Orange `#FF5B2E`
- Orange Dark `#D93B1F`
- Navy `#0B3478`
- Ink `#1E2530`
- Dark Panel `#202A38`
- Warm Beige `#FFD4A5`
- Pale Blue `#EEF3FB`
- White `#FFFFFF`

외부 회사 로고는 추가하지 않습니다. 로고가 필요하면 사용자가 제공한 승인된 자산만 사용합니다.
