# PPT 출고 전 QA

## Fact

- [ ] `100 → 88 → 100`은 초기 재고 100, 출고 12, 잔량 88, 전체 취소 후 100을 의미합니다.
- [ ] 상태는 `COMPLETED → CANCELED`만 사용합니다.
- [ ] 이동유형 쌍은 `221/222`, `M75/M76`, `M77/M78`입니다.
- [ ] `23/23`은 효과 지표가 아니라 자동 테스트 결과입니다.
- [ ] 중복·재고 부족·재취소 실패는 재고와 이력을 바꾸지 않습니다.

## Structure

- [ ] 제목만 읽어도 문제 → 결정 → 데모 → 증거가 이어집니다.
- [ ] 한 슬라이드에 하나의 핵심 메시지만 있습니다.
- [ ] 완료 주장에 Source·Location·Test가 연결됩니다.
- [ ] 범위 밖 항목이 구현된 기능처럼 보이지 않습니다.

## Visual

- [ ] 반복 카드·배지·영어 라벨을 제거했습니다.
- [ ] 실제 파일명·숫자·상태·테스트가 시각의 중심입니다.
- [ ] 본문 핵심 글씨는 스크린에서 읽힐 크기입니다.
- [ ] 겹침·잘림·불의의 줄바꿈이 없습니다.
- [ ] PowerPoint에서 직접 열어 한글과 발표자 노트를 확인했습니다.

## Repeatability

- [ ] 생성 소스가 `output/generator/`에 있습니다.
- [ ] 수정 후 동일한 명령으로 PPT를 다시 만들 수 있습니다.
- [ ] `output/qa_report.md`에 검수 결과와 남은 제약을 기록했습니다.
