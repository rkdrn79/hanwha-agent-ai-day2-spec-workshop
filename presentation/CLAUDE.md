# Presentation workspace rules

- `.claude/skills/create-solution-ppt/SKILL.md`와 `.claude/skills/pptx/SKILL.md`를 함께 사용한다.
- `presentation/BRIEF.md`를 이번 프로젝트의 청중·장수·경로·스타일 설정으로 사용한다.
- Brief가 지정한 근거 위치와 시각 레퍼런스를 먼저 확인한다.
- `presentation/work/`에 source map, storyboard, outline, design contract, 생성 소스를 만든다.
- 구성안에서 멈추지 않고 `presentation/output/`에 편집 가능한 PPTX를 만든다.
- 전 장을 렌더링하고 contact sheet와 개별 슬라이드를 확인한다.
- contact sheet를 스타일 레퍼런스와 비교해 화면 리듬을 검수한다.
- 수정은 PPTX가 아니라 outline 또는 생성 소스에 반영한 뒤 전체를 다시 만든다.
- 제품 문서·소스·테스트는 발표자료에 맞추기 위해 수정하지 않는다.
- 구조 검증과 시각 검수가 끝난 뒤에만 완료라고 보고한다.
